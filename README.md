# AI-Hospital: MedAgentSim re-implementation

A simulated clinic in which an LLM **doctor agent** must diagnose a **patient agent** through
multi-turn conversation, ordering exams from a **measurement agent**. The doctor starts with
almost no information. Based on *Self-Evolving Multi-Agent Simulations for Realistic Clinical
Interactions* (MedAgentSim, arXiv:2503.22678).

**Phase 1 status:** baseline **Multi-Agent Clinic** implemented end to end (data → agents →
tools → judge → metrics). Memory / reflection / CoT / ensembling (Phase 2) have defined interfaces.
See [docs/architecture.md](docs/architecture.md).

## Quick start

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate     macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt

pytest -q                                                       # unit + end-to-end tests
python scripts/run_baseline.py --config configs/smoke_mock.yaml -v   # offline demo, no API key
```

## Running the baseline with a real model

```bash
# 1. Data: downloads AgentClinic MedQA / MedQA-Ext / NEJM / NEJM-Ext and converts them
python scripts/prepare_data.py

# 2. Keys
cp .env.example .env        

# 3. Run (first 20 cases, live dialogue)
python scripts/run_baseline.py --config configs/baseline_medqa_groq.yaml --n 20 -v

# 4. Full run, then compare runs as a markdown table
python scripts/run_baseline.py --config configs/baseline_medqa_groq.yaml
python scripts/evaluate.py runs/<run_dir_1> runs/<run_dir_2> --table
```

Interrupted runs can continue with `--resume runs/<run_dir>`.
To use a local model instead: `configs/baseline_medqa_ollama.yaml` (Ollama) or point `base_url` at a vLLM server.

**Control Mode** (you play a role against the AI):
```bash
python scripts/run_baseline.py --config configs/baseline_medqa_groq.yaml --n 1 --human doctor
```

## Outputs

`runs/<run_name>-<timestamp>/`
- `config.yaml`: the exact config used
- `episodes.jsonl`: one `EpisodeResult` per case (full transcript, tests, diagnosis, verdict, tokens)
- `metrics.json`: accuracy + 95% CI, avg turns/tests, timeout rate, token usage per role

A sample is committed in [runs/sample/smoke_mock](runs/sample/smoke_mock).

## Datasets

| Name | Cases | Source | Notes |
|---|---|---|---|
| `medqa` | 107 | AgentClinic | OSCE format, main Phase 1 benchmark |
| `medqa_ext` | 215 | AgentClinic | |
| `nejm` | 15 | AgentClinic | image-based; needs `image_reader` (VLM) |
| `nejm_ext` | 120 | AgentClinic | |


Each dataset is split into `<name>_dev.jsonl` (prompt iteration) and `<name>_test.jsonl` (seed 0).
`data/smoke/` holds 3 hand-written cases for tests.

## Repository layout

```
configs/            run configs (provider + model per agent role)
data/smoke/         tiny hand-written test cases
data/processed/     unified Case JSONL (generated by prepare_data.py)
docs/               architecture.md, results_phase1.md
scripts/            prepare_data.py, run_baseline.py, evaluate.py
src/medsim/
  contracts.py      pydantic schemas shared by all modules
  config.py         RunConfig
  providers/        LLMProvider: openai_compat, mock, human
  agents/           doctor / patient / measurement agents + prompts
  tools/            doctor action parser, image reader (VLM)
  env/              EpisodeRunner (conversation state machine)
  eval/             LLM judge, metrics (Wilson CI)
  memory/           MemoryBuffer interface (Phase 2)
  data/             dataset converters / loaders
  pipeline.py       config -> run -> episodes.jsonl + metrics.json
tests/              pytest suite (runs offline with mock provider)
```
